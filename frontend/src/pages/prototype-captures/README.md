# Protótipo #293 — proposta para aprovação

Branch: `prototype/293` (protótipo descartável, dados fictícios). A decisão visual também orienta #294.

Execute o frontend da branch em uma porta livre, com `BACKEND_URL` apontando para uma porta sem serviço, e abra `/chamados?prototype=293&variant=A`. A barra inferior permite simular prazo expirado, mensagem em envio, falha e temas. No menu da mensagem, experimente editar ou excluir; o rascunho volta ao cancelar ou salvar.
